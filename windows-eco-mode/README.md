# Эконом-режим для ноутбука (Windows 10 / 11)

Два bat-файла. Оба сами запрашивают права администратора (UAC), достаточно двойного клика.

| Файл | Что делает |
|---|---|
| `eco_on.bat` | Включает эконом-режим: яркость 50 %, процессор от батареи 30 %, диски и шины в режим экономии, «Экономия заряда» Windows всегда включена, некритичные фоновые службы остановлены. Исходное состояние сохраняется. |
| `eco_off.bat` | Возвращает всё как было: исходная схема питания, яркость, службы, фоновые приложения. |

Файл состояния: `C:\ProgramData\EcoMode\state.txt` (создаёт `eco_on.bat`, читает и убирает `eco_off.bat`).

## Что меняет `eco_on.bat`

Создаётся **отдельная** схема электропитания «Eco» как копия текущей (обычно «Сбалансированная»), и меняется только она. Исходная схема не трогается, поэтому возврат точный.

| Группа | От батареи | От сети |
|---|---|---|
| Яркость экрана | 50 % (адаптивная яркость выкл.) | 50 % |
| Макс. состояние процессора | **30 %** (проверено: время работы ×2) | 100 % |
| Турбо-буст, охлаждение, энергоэффективность CPU | буст выкл., охлаждение пассивное, EPP 100 | не меняется |
| Отключать жесткий диск | через 1 мин | через 1 мин |
| AHCI / NVMe | HIPM+DIPM, NVMe NOPPME | то же |
| PCI Express (ASPM) | максимальное энергосбережение | то же |
| USB | выборочная приостановка, USB3 LPM максимум | то же |
| Wi-Fi адаптер | средний режим экономии, **адаптер не отключается** | то же |
| Видео / медиа | приоритет экономии | то же |
| Слайд-шоу обоев | пауза | пауза |
| Графика Intel / AMD / переключаемая | режим экономии (если настройка есть) | то же |
| «Экономия заряда» Windows | всегда включена, без доп. затемнения | всегда включена |

**Не трогается:** сон, гибернация, отключение экрана и их таймеры, действия крышки и кнопок, таймеры пробуждения, Wi-Fi, Bluetooth, сеть.

Все значения в блоке `НАСТРОЙКИ` в начале `eco_on.bat` можно поменять: `BRIGHTNESS`, `CPU_MAX_DC`, `CPU_MAX_AC`, `CPU_MIN`, `CPU_EPP`, `WIFI_PWR`, `DISK_OFF`, `SERVICES`.

## Службы: что останавливается и почему это безопасно

Останавливаются и отключаются (тип запуска сохраняется, `eco_off.bat` возвращает его и запускает службу обратно):

| Служба | Что это | Побочный эффект в эконом-режиме |
|---|---|---|
| `WSearch` | индексация поиска Windows, грузит диск и CPU в фоне | поиск в «Пуске» и Проводнике работает медленнее, поиск в Outlook неполный |
| `SysMain` | Superfetch, предзагрузка программ в память | программы запускаются чуть медленнее |
| `DiagTrack` | телеметрия Microsoft | нет |
| `DoSvc` | оптимизация доставки, раздача обновлений другим ПК | загрузки из Microsoft Store приостановлены |
| `wuauserv` | Центр обновления Windows: проверка и скачивание обновлений | обновления не ставятся, пока включён эконом-режим (уберите из списка, если это нежелательно) |
| `MapsBroker` | загрузка автономных карт | нет |
| `WMPNetworkSvc` | общий доступ к медиа (DLNA) | нет |
| `XblAuthManager`, `XblGameSave`, `XboxNetApiSvc`, `XboxGipSvc` | службы Xbox | приложение Xbox и Game Pass не работают |

Если службы нет на компьютере, она просто пропускается.

**Сознательно не трогаются** (критичные для системы, сети или безопасности):

- сеть и Wi-Fi: `WlanSvc`, `Dhcp`, `Dnscache`, `NlaSvc`, `Netman`, `Wcmsvc`, `bthserv`;
- безопасность: `WinDefend`, `WdNisSvc`, `SecurityHealthService`, `mpssvc` (брандмауэр), `BFE`, `wscsvc`, `CryptSvc`, `BITS` (через него обновляется Защитник);
- ядро системы: `RpcSs`, `DcomLaunch`, `Schedule`, `EventLog`, `Power`, `PlugPlay`, `Winmgmt`, `ProfSvc`, `UserManager`, `TimeBrokerSvc`, `SystemEventsBroker`, `BrokerInfrastructure`, `StateRepository`, `AppXSvc`;
- вход и лицензии: `wlidsvc` (учётная запись Microsoft), `TokenBroker`, `ClipSVC`, `LicenseManager`, `WbioSrvc` (отпечаток / лицо);
- интерфейс и устройства: `Audiosrv`, `AudioEndpointBuilder`, `Themes`, `UxSms`, `TabletInputService`, `camsvc`, `Spooler`;
- `UsoSvc` и `WaaSMedicSvc` защищены самой Windows и остановке не поддаются.

Дополнительно включается политика «запретить фоновую работу приложений Microsoft Store» (`LetAppsRunInBackground = 2`), `eco_off.bat` её снимает.

## Замечания

- Яркость меняется только у встроенного экрана ноутбука (через WMI), внешние мониторы не затрагиваются.
- Пока активна схема «Eco», в «Параметрах» Windows 11 ползунок «Режим питания» недоступен: это нормально для любой схемы кроме «Сбалансированной». Схема видна в Панели управления → Электропитание.
- Фирменные утилиты (Lenovo Vantage, Dell Power Manager, ASUS Armoury Crate, MSI Center и т. п.) могут перебивать настройки схемы своими режимами.
- Файлы должны быть сохранены в кодировке **UTF-8 без BOM** (так они лежат в репозитории). Если в окне вместо русского текста «кракозябры», файл пересохранён в другой кодировке.
- При первом запуске скачанного файла SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».
- Повторный запуск `eco_on.bat` безопасен: сохранённое исходное состояние не перезаписывается, настройки применяются заново.
