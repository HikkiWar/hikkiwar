# Эконом-режим для ноутбука (Windows 10 / 11)

Два bat-файла. Оба сами запрашивают права администратора (UAC), достаточно двойного клика.

| Файл | Что делает |
|---|---|
| `eco_on.bat` | Включает эконом-режим: яркость 50 %, процессор от батареи 30 %, диски и шины в режим экономии, «Экономия заряда» Windows всегда включена, некритичные фоновые службы остановлены. Исходное состояние сохраняется. |
| `eco_off.bat` | Возвращает всё как было: исходная схема питания, яркость, службы, фоновые приложения. |

Рабочая папка обоих скриптов: `C:\ProgramData\EcoMode`

| Файл | Назначение |
|---|---|
| `state.txt` | исходные настройки, создаёт `eco_on.bat`, читает и переименовывает в `state.last.txt` `eco_off.bat` |
| `eco.log` | журнал обоих скриптов: каждая команда, её вывод и код ошибки |

## Что меняет `eco_on.bat`

Создаётся **отдельная** схема электропитания «Eco» как копия текущей (обычно «Сбалансированная»), и меняется только она. Исходная схема не трогается, поэтому возврат точный.

| Группа | От батареи | От сети |
|---|---|---|
| Яркость экрана | 50 % (адаптивная яркость выкл.) | 50 % |
| Макс. состояние процессора | **30 %** (проверено: время работы ×2) | 100 % |
| Турбо-буст, охлаждение, энергоэффективность CPU | буст выкл., охлаждение пассивное, EPP 100 | не меняется |
| Отключать жесткий диск | через 1 мин | через 1 мин |
| AHCI / NVMe | HIPM+DIPM, NVMe NOPPME | то же |
| PCI Express (ASPM) | максимальное энергосбережение | то же |
| USB | выборочная приостановка, USB3 LPM максимум | то же |
| Wi-Fi адаптер | средний режим экономии, **адаптер не отключается** | то же |
| Сеть в режиме ожидания (сон) | выкл.: во сне ноутбук не держит Wi-Fi и не качает в фоне | не меняется |
| Видео / медиа | приоритет экономии | то же |
| Слайд-шоу обоев | пауза | пауза |
| Графика Intel / AMD / переключаемая | режим экономии (если настройка есть) | то же |
| «Экономия заряда» Windows | всегда включена, без доп. затемнения | всегда включена |
| Защитник Windows | плановые проверки выкл., лимит CPU для проверок 5 %, защита в реальном времени выкл. (см. ниже) | то же |

**Не трогается:** сон, гибернация, отключение экрана и их таймеры, действия крышки и кнопок, таймеры пробуждения, Wi-Fi, Bluetooth, сеть.

Все значения в блоке `НАСТРОЙКИ` в начале `eco_on.bat` можно поменять: `BRIGHTNESS`, `CPU_MAX_DC`, `CPU_MAX_AC`, `CPU_MIN`, `CPU_EPP`, `WIFI_PWR`, `DISK_OFF`, `DEFENDER_OFF`, `SERVICES`.

## Службы: что останавливается и почему это безопасно

Останавливаются и отключаются (тип запуска сохраняется, `eco_off.bat` возвращает его и запускает службу обратно):

| Служба | Что это | Побочный эффект в эконом-режиме |
|---|---|---|
| `WSearch` | индексация поиска Windows, грузит диск и CPU в фоне | поиск в «Пуске» и Проводнике работает медленнее, поиск в Outlook неполный |
| `SysMain` | Superfetch, предзагрузка программ в память | программы запускаются чуть медленнее |
| `DiagTrack` | телеметрия Microsoft | нет |
| `WerSvc` | отчёты об ошибках (Windows Error Reporting) | при падении программы нет окна «прекратила работу», отчёт не отправляется |
| `DoSvc` | оптимизация доставки, раздача обновлений другим ПК | загрузки из Microsoft Store приостановлены |
| `wuauserv` | Центр обновления Windows: проверка и скачивание обновлений | обновления не ставятся, пока включён эконом-режим (уберите из списка, если это нежелательно) |
| `InstallService` | установка и обновление приложений Microsoft Store | Store не ставит и не обновляет приложения в эконом-режиме |
| `MapsBroker` | загрузка автономных карт | нет |
| `WMPNetworkSvc` | общий доступ к медиа (DLNA) | нет |
| `XblAuthManager`, `XblGameSave`, `XboxNetApiSvc`, `XboxGipSvc` | службы Xbox | приложение Xbox и Game Pass не работают |
| `edgeupdate`, `edgeupdatem`, `gupdate`, `gupdatem` | автообновление Edge и Google | браузеры не обновляются, пока включён эконом-режим |

Если службы нет на компьютере, она просто пропускается.

**Сознательно не трогаются** (критичные для системы, сети или безопасности):

- сеть и Wi-Fi: `WlanSvc`, `Dhcp`, `Dnscache`, `NlaSvc`, `Netman`, `Wcmsvc`, `bthserv`;
- безопасность: службы `WinDefend`, `WdNisSvc`, `SecurityHealthService`, `mpssvc` (брандмауэр), `BFE`, `wscsvc`, `CryptSvc`, `BITS`. Защитник управляется только штатной командой `Set-MpPreference`, см. раздел ниже;
- ядро системы: `RpcSs`, `DcomLaunch`, `Schedule`, `EventLog`, `Power`, `PlugPlay`, `Winmgmt`, `ProfSvc`, `UserManager`, `TimeBrokerSvc`, `SystemEventsBroker`, `BrokerInfrastructure`, `StateRepository`, `AppXSvc`;
- вход и лицензии: `wlidsvc` (учётная запись Microsoft), `TokenBroker`, `ClipSVC`, `LicenseManager`, `WbioSrvc` (отпечаток / лицо);
- интерфейс и устройства: `Audiosrv`, `AudioEndpointBuilder`, `Themes`, `UxSms`, `TabletInputService`, `camsvc`, `Spooler`;
- `UsoSvc` и `WaaSMedicSvc` защищены самой Windows и остановке не поддаются.

## Политики реестра

Ставятся как политики (ветка `HKLM\SOFTWARE\Policies`), исходные значения сохраняются, `eco_off.bat` возвращает их или удаляет:

| Политика | Эффект |
|---|---|
| `AppPrivacy\LetAppsRunInBackground = 2` | приложения Microsoft Store не работают в фоне |
| `Dsh\AllowNewsAndInterests = 0` | виджеты Windows 11 выключены, процессы `Widgets.exe` и `WidgetService.exe` закрываются (кнопка на панели задач пропадёт после перезагрузки или выхода из системы) |
| `Windows Feeds\EnableFeeds = 0` | «Новости и интересы» Windows 10 выключены |
| `Edge\StartupBoostEnabled = 0`, `Edge\BackgroundModeEnabled = 0` | Edge не висит в памяти после закрытия и не стартует заранее (применится после перезапуска Edge) |
| `Chrome\BackgroundModeEnabled = 0` | Chrome не работает в фоне после закрытия окна |
| `DataCollection\AllowTelemetry = 0` | диагностические данные Windows на минимум (на Home/Pro Windows считает это уровнем «обязательные») |
| `Windows Error Reporting\Disabled = 1` | отчёты об ошибках не собираются и не отправляются |
| `WindowsAI\DisableAIDataAnalysis = 1` | снимки Recall на Copilot+ ПК выключены (на остальных ничего не меняет) |
| `Edge\DiagnosticData = 0`, `Chrome\MetricsReportingEnabled = 0` | браузеры не отправляют диагностику |

## Телеметрия, отчёты об ошибках, проверки обновлений

Отключается на трёх уровнях, чтобы ничего не просыпалось в фоне:

1. **Службы:** `DiagTrack` (телеметрия), `WerSvc` (отчёты об ошибках), `wuauserv` и `DoSvc` (Центр обновления и доставка), `InstallService` (обновления Store), автообновление Edge и Google.
2. **Политики:** телеметрия на минимум, отчёты об ошибках выкл., диагностика Edge и Chrome выкл. (таблица выше).
3. **Задания планировщика** (список `TASKS` в начале `eco_on.bat`, исходное состояние каждого сохраняется): оценка совместимости `Microsoft Compatibility Appraiser` (процесс `CompatTelRunner.exe`, один из главных пожирателей CPU в фоне), `ProgramDataUpdater`, `PcaPatchDbTask`, программа улучшения качества (`Consolidator`, `UsbCeip`), `Autochk\Proxy`, отзывы (`DmClient`), отчёты об ошибках (`QueueReporting`), сбор диагностики дисков и системы, `Device Information`, `Sqm-Tasks`, `GatherNetworkInfo`, `BackgroundConfigSurveyor`, `WinSAT`, `AnalyzeSystem`, `Metadata Refresh`, фоновые проверки обновлений Windows (`WindowsUpdate\Scheduled Start`) и Store (`InstallService\*`), загрузка речевых моделей и карт, синхронизация параметров, Xbox, Office-телеметрия. Задания, которых нет на компьютере, пропускаются.

Что Windows не даёт отключить, и скрипт не пытается: службы `UsoSvc` и `WaaSMedicSvc` и задания `UpdateOrchestrator\*` защищены системой. `WaaSMedicSvc` может сам вернуть службе `wuauserv` тип запуска «вручную», это нормально, `eco_off.bat` в любом случае вернёт исходное.

## Защитник Windows

В простое Защитник ест мало. Батарею съедают плановые и «догоняющие» проверки, которые стартуют в фоне когда им вздумается, и проверка файлов при копировании. Поэтому `eco_on.bat` всегда делает безопасную часть, которая не снижает защиту:

- плановые проверки выключены (`ScanScheduleDay = 8`, «никогда»);
- «догоняющие» проверки после пропущенных выключены;
- проверки только в простое и с лимитом 5 % CPU вместо 50 %.

Отключение защиты в реальном времени (`DEFENDER_OFF=1`, включено по умолчанию) делается штатной командой `Set-MpPreference -DisableRealtimeMonitoring $true`. Ограничения заложены самой Windows:

- Если в Безопасности Windows включена **«Защита от подделки»** (Tamper Protection, по умолчанию включена), команда не сработает, и скрипт честно об этом напишет. Отключить её можно только вручную: Безопасность Windows → Защита от вирусов и угроз → Управление настройками → Защита от подделки → Выкл. Скрипт эту защиту не обходит.
- Windows сама включает защиту в реальном времени обратно через некоторое время или после перезагрузки. Это нормально.
- Если стоит сторонний антивирус, Защитник находится в пассивном режиме, и скрипт его не трогает. Сторонний антивирус скрипт не отключает, у него для этого есть свои режимы.

Без защиты в реальном времени ноутбук уязвим ко всему, что приходит из сети и с флешек. Выигрыш по батарее от этого шага небольшой по сравнению с отключением плановых проверок. Если защита важнее, поставьте `DEFENDER_OFF=0`.

`eco_off.bat` возвращает защиту в реальном времени и все настройки проверок к сохранённым значениям.

## Что ещё можно выжать вручную

Эти вещи скрипт не делает, потому что они либо зависят от модели ноутбука, либо выходят за рамки «сон не трогать»:

- `WIFI_PWR=3` в `eco_on.bat`: максимальная экономия Wi-Fi. Даёт ещё немного, но на части адаптеров связь начинает отваливаться, поэтому по умолчанию стоит 2.
- Частота обновления экрана: если панель 90/120/144 Гц, поставьте 60 Гц (Параметры → Система → Дисплей → Расширенные параметры). На таких панелях это одна из самых заметных экономий.
- Подсветка клавиатуры выкл. (клавиши Fn, у каждой модели свои).
- Закрытие крышки → гибернация вместо сна. На современных ноутбуках «сон» (Modern Standby) тратит 1–2 % в час, в сумке за ночь уходит до 20 %. Панель управления → Электропитание → Действие при закрытии крышки.
- Проверить состояние батареи: `powercfg /batteryreport`, в отчёте сравните Design Capacity и Full Charge Capacity. Если ёмкость упала вдвое, никакие настройки этого не вернут.

## Журнал и ошибки

Оба скрипта пишут в `C:\ProgramData\EcoMode\eco.log`. Для каждого запуска там заголовок с датой, именем компьютера и пользователя, затем каждая выполненная команда (`> команда`), её полный вывод и код завершения, содержимое `state.txt` и итоговая строка с числом ошибок. Когда журнал вырастает больше 1 МБ, он переименовывается в `eco.log.old` и начинается заново.

Ошибки делятся на два вида:

- **Допустимые** (в журнале `пропущено, код N`): настройка или служба отсутствует на этом ноутбуке, служба и так не запущена, схема «Eco» ещё не создавалась. Такие не считаются и на экран не выводятся.
- **Настоящие** (в журнале `ОШИБКА, код N`, на экране `[x] ошибка, код N: команда`): не создалась или не активировалась схема «Eco», не записался файл состояния, не отключилась или не восстановилась служба, не записалась политика, упал шаг PowerShell. Они считаются, и в конце работы скрипт пишет `ошибок: N` и где смотреть подробности.

Шаги на PowerShell (задания планировщика, Защитник) ловят исключения сами и пишут на экран и в журнал, какое именно задание или команда не сработали и почему. Если что-то пошло не так, пришлите `eco.log` целиком: там видно, на какой команде и с каким текстом ошибки остановился шаг.

## Замечания

- Яркость меняется только у встроенного экрана ноутбука (через WMI), внешние мониторы не затрагиваются.
- Пока активна схема «Eco», в «Параметрах» Windows 11 ползунок «Режим питания» недоступен: это нормально для любой схемы кроме «Сбалансированной». Схема видна в Панели управления → Электропитание.
- Фирменные утилиты (Lenovo Vantage, Dell Power Manager, ASUS Armoury Crate, MSI Center и т. п.) могут перебивать настройки схемы своими режимами.
- Файлы должны быть сохранены в кодировке **UTF-8 без BOM** (так они лежат в репозитории). Если в окне вместо русского текста «кракозябры», файл пересохранён в другой кодировке.
- При первом запуске скачанного файла SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».
- Повторный запуск `eco_on.bat` безопасен: сохранённое исходное состояние не перезаписывается, настройки применяются заново.
